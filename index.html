PPT로 내보내기

내보낼 그룹을 선택하세요. 여러 그룹을 선택하면 하나의 PPTX 파일로 합쳐집니다.

전체 선택 전체 해제

프로젝트 저장 (.wsproj)

저장할 그룹을 선택하세요. 여러 그룹을 함께 고를 수 있고, 선택한 그룹의 배경 이미지·영상도 한 파일에 같이 담깁니다.

전체 선택 전체 해제

레이아웃은 배경 이미지·영상까지 파일에 담겨서, 다른 컴퓨터에서 이 프로젝트를 열면 레이아웃 목록에 들어갑니다. 쓰이는 것만 담으므로 받는 컴퓨터에 쓰지 않는 레이아웃이 쌓이지 않습니다. 단, 폰트 파일은 포함되지 않으므로 같은 폰트가 설치된 PC에서 가장 정확하게 보입니다.

프로젝트 삽입

점선 상자가 추가될 그룹입니다. 기존 그룹 사이의 ＋ 여기에 넣기를 눌러 넣을 위치를 정하고, 추가하지 않을 그룹은 체크를 해제하세요.

슬라이드 편집

첫 줄을 <곡 제목>처럼 꺽쇠로 감싸면 노래 제목으로 인식해 첫 번째 슬라이드로 만듭니다. 꺽쇠 기호는 슬라이드에 표시되지 않습니다.
줄 (1~5)
체크 후 AI 슬라이드 생성을 누르면 각 슬라이드에 번역 텍스트 상자가 함께 추가됩니다.
내 삶에 역사하시는 신실한 나의 하나님을 찬양해
번역 체크 시 이 위치에 번역문이 표시됩니다
저장된 레이아웃:
가사 외에 영어 번역, 일본어 번역, 안내 문구 같은 텍스트를 추가할 수 있습니다.
선택 시 AI가 생성하는 모든 슬라이드에 이 레이아웃의 폰트·텍스트 박스·위치가 적용됩니다.

설정

API 키는 각자 컴퓨터의 설정 파일에만 저장됩니다. 위에서 고른 AI 제공자의 키를 넣어야 하며, 다른 제공자의 키를 넣으면 저장되지 않습니다.
